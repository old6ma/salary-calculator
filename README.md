# salary-calculator · 薪有数

中国大陆居民个人工资薪金测算网页。输入税前月薪、年薪月数和城市，查看逐月现金、全年到手、公积金账户与奖金计税对比。计算在浏览器执行，无服务端、不上传薪资。

## 本地运行

要求 Node.js 24 或以上。

```bash
npm install
npm run dev
```

访问 **http://localhost:5173**。默认仅绑定 localhost，端口占用时直接报错，不切换端口。服务器停止后，重新执行启动命令即可。

```bash
npm test
npm run typecheck
npm run build
npm run preview
```

`preview` 同样使用 localhost:5173，需先停止开发服务。测试采用 Node 内置 runner；较早的 Node 24 版本可能显示 Type Stripping 实验性提示，不影响运行。

## 使用与口径

- 默认示例：北京、2026、40k × 16；额外4薪假定12月作为一笔符合条件的全年一次性奖金，需按实际 offer 修改。
- 公积金比例不填时自动按所选城市正常政策最低比例估算，不代表公司实际比例；可手动填写，个人和单位分别记录。补充公积金默认关闭。
- 未填写基数时按合同月薪估算，各险种分别封顶。新入职、试用期、上年度平均工资等会影响实际申报，应核对 HR 或工资单。
- 月度税额按累计预扣；全年到手为该自然年12个月实际发放现金减个人实缴和预扣税的合计。年收入折合月均不等于普通月到账。
- 年度汇算估计另列。预计退税不提前加入年内现金，奖金单独/合并的最终比较不改变已选实际预扣账单。
- 次年发放事件单列，不计本年度；2027未发布地方参数沿用2026年末标准并标注预测，不声称为未来官方标准。
- 入职当年按整月入职、单一雇主、无其他综合所得估算。实习劳务、前雇主收入、非居民、股权、跨境等复杂情形不在本版范围。
- 个人年金实缴与允许扣除额分开；单位年金默认假设合规，工资单中的应税部分应另行填写，不能用个人8%上限推定单位整体年金是否合规。
- 补充保险单位保费可能影响个税。不知道税务属性时展示应税/已获确认免税两种假设；符合税优健康险时可按实际允许额填写，不能把所有补充医疗保费全额抵税。
- “其他专项附加扣除”请填符合条件的金额，不能与已选租金重复，租金与房贷利息扣除不能同时享受；仅年度汇算扣除不影响月度账单。

## 城市覆盖与证据限制

首版提供北京、上海、深圳、杭州和自定义地区选择。**北京、上海可按现有预设直接估算；深圳、杭州存在尚未核实的2026个人失业费率及部分城市参数，必须填写实际失业费率并确认参数后计算。** 页面不会将其标为完整官方核实预设，也不会把2025年底已到期的费率优惠静默延长。

这些待核对项有意阻止缺参情况下输出看似精确的金额。可使用“自定义地区”填写实际已知参数；有些来源仅搜索索引可读、原文访问受限，详见 [证据清单](docs/research/city-policy-sources.md)。本地参数不是实时政策服务，应结合最新主管部门通知更新。

## 项目结构

- `src/domain`：金额（整数分）、类型及示例输入。
- `src/policies`：按月份匹配的城市规则、来源、预测/缺项状态。
- `src/calculator`：日历、个人扣款、税前扣除、预扣及年度汇算纯函数。
- `src/components`：表单、结果卡、现金图、月度明细和政策依据。
- `src/lib`：版本化本地保存和CSV导出。
- `docs/research`：全国政策与城市参数核验记录。

## 更新政策

1. 查阅对应人社、医保、公积金和税务主管部门文件，分别记录生效时间、发布日期与核验日。
2. 更新 `src/policies/cities.ts` 中该城市、该时段的险种基数/个人费率、固定附加费、公积金及税前扣除限额、取整规则与来源。
3. 仅在证据齐全时删除 `missing`/`incomplete` 状态；地方文件到期不得直接推定延期。
4. 在 `cities.test.ts` 增加生效边界，在计算测试补充独立预期金额，然后执行上述检查。

localStorage可通过页面“删除本地数据”清除；不收集身份证、地址或账户信息。
